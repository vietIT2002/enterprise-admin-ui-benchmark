# Customer detail (CRM)

## Prompt (EN)
Create the customer detail page for a CRM: customer information, contacts, recent orders and activity history. It should look like a professional business application.

## Prompt (VI)
Tạo trang chi tiết khách hàng cho hệ thống CRM: thông tin khách hàng, người liên hệ, đơn hàng gần đây và lịch sử hoạt động. Giao diện như phần mềm doanh nghiệp chuyên nghiệp.

## Acceptance checklist
- [ ] A breadcrumb shows the path back to the customer list and includes the customer's name
- [ ] The record header shows name and ID, a status badge with text, at most four key fields and exactly one primary action
- [ ] Secondary actions are grouped in an overflow menu
- [ ] Content is organised in sections or tabs, not a long stack of unrelated cards
- [ ] The activity history is a timeline with absolute timestamps (relative times only with the absolute value available)
- [ ] The recent orders table right-aligns amounts and formats currency
- [ ] Sections without data show an empty state with a next step
- [ ] Avatars appear only for people; the company is shown with its logo or no image
