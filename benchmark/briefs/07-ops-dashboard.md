# Warehouse operations dashboard

## Prompt (EN)
Build an operations dashboard for a warehouse management system: today's key numbers, trends, and the things that need attention.

## Prompt (VI)
Làm dashboard vận hành cho hệ thống quản lý kho: các chỉ số chính trong ngày, xu hướng, và những việc cần xử lý.

## Acceptance checklist
- [ ] There is no greeting or hero; the header has a title and a date-range control
- [ ] Each KPI tile shows label, value and a signed change with its comparison period, without decorative icon tiles
- [ ] Charts use bars for comparison and lines for trends; no pie, donut or gauge; axes have labels and units
- [ ] A needs-attention list links to pre-filtered list pages
- [ ] Numbers use locale formatting and tabular figures
- [ ] Each widget has loading and empty states
