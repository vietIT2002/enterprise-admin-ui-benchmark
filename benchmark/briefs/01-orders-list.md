# Orders list (ERP sales)

## Prompt (EN)
Build the orders management page for our ERP sales module: a list of orders with search, filters, order status and bulk actions. Make it look professional.

## Prompt (VI)
Làm trang quản lý đơn hàng cho phân hệ bán hàng của hệ thống ERP: danh sách đơn có tìm kiếm, bộ lọc, trạng thái đơn và thao tác hàng loạt. Giao diện chuyên nghiệp.

## Acceptance checklist
- [ ] The orders table starts in the first viewport; no KPI cards, hero or greeting above it
- [ ] Page header has a plural title and exactly one primary action (create order)
- [ ] 2–3 filters are visible; applied filters show as removable chips with a clear-all control
- [ ] Status tabs or saved views show counts
- [ ] Bulk selection has a header checkbox with an indeterminate state and a bulk bar showing the selected count
- [ ] When results span pages, the user can select all matching results, not just the visible page
- [ ] Amounts are right-aligned with tabular figures and locale currency formatting; dates are absolute
- [ ] Filtering to zero results shows a no-results state with a way to clear filters, distinct from the first-use empty state
- [ ] Row actions show at most two visible controls; icon-only controls have accessible names
- [ ] A destructive bulk action (cancel orders) asks for confirmation naming the count and the consequence
