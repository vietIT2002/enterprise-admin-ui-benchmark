# Expense request approval (workflow)

## Prompt (EN)
Create the expense request approval screen: request details, attachments, multi-level approval steps, and approve or reject with a comment.

## Prompt (VI)
Tạo màn hình duyệt đề nghị thanh toán: chi tiết đề nghị, chứng từ đính kèm, các cấp duyệt nhiều bước, và nút duyệt hoặc từ chối kèm ghi chú.

## Acceptance checklist
- [ ] Status uses a consistent vocabulary with text labels, not colour alone
- [ ] Approval steps show approver, decision and absolute timestamp for each level
- [ ] Approve is the single primary action; Reject is secondary and requires a reason
- [ ] Only the current approver can act; other users see why they cannot
- [ ] Amounts are prominent, right-aligned in line items and formatted as currency
- [ ] Attachments are listed with name, type and size and can be previewed or downloaded
- [ ] A history timeline records every action on the request
