Tải file lên

Chọn file CSV chứa danh sách sản phẩm. Dòng đầu tiên là tiêu đề cột.

Kéo thả file CSV vào đây

hoặc

  • Định dạng .csv, mã hóa UTF-8, phân tách bằng dấu phẩy hoặc chấm phẩy.
  • Tối đa 5,0 MB và 5.000 dòng mỗi lần nhập.
  • Bắt buộc có các cột: mã SKU, tên sản phẩm, đơn vị tính, giá bán. nếu chưa có.
